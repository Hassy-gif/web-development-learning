# Task 7 Notes

## What is an API?
An API is a way for different applications to communicate with each other and share data. In this project, I used an API to get user information for my React application.

## What does fetch() do?
fetch() sends a request to an API and allows the application to receive data from it.

## Why is useEffect() used?
useEffect() is used to run code after the component loads. I used it to fetch the users from the API when the application first opens.

## Why is useState() used?
useState() allows a React component to store and update data. I used it to keep track of the users, search input, loading state, and errors.

## How does the application receive data from the API?
The application uses fetch() to request data from the JSONPlaceholder API. The response is converted to JSON and then stored in the users state so React can display it.

## What did you learn from this task?
I learned how a React application can communicate with an API and display the data it receives. I also learned how to use reusable components, handle loading and errors, and filter users based on what someone types in the search box.
